## 2. Background-Mini-Bar (`MainTabView.swift` oder Root-Container)

### Shared Hook

`AiGenerationManager` ist ein Koin-Single — über `KoinHelper`-Bridge in Swift verfügbar. Folgendes muss observiert werden:

- `manager.state: StateFlow<AiGenerationState>` — exportiert via KMP-NativeCoroutines
- `AiGenerationState` ist sealed; Swift sieht (per KMP-Native-Konvention): `.idle`, `.generating(type, originatingData)`, `.success(type, preview, originatingData)`, `.error(type, exception, originatingData)`
- `AiType` enum: `.workout` / `.recipe`

Observation-Pattern wie `ThemeManager` (siehe `iosApp/iosApp/Theme/ThemeManager.swift` post-v1.5-Pattern):

```swift
@MainActor
final class AiGenerationObserver: ObservableObject {
    @Published var state: AiGenerationState = AiGenerationStateIdle.shared

    private let manager: AiGenerationManager

    init(manager: AiGenerationManager) {
        self.manager = manager
        Task { [weak self] in
            for await s in asyncSequence(for: manager.state) {
                guard let self else { return }
                await MainActor.run { self.state = s }
            }
        }
    }
}
```

(Falls `asyncSequence(for:)` nicht direkt verfügbar ist, nutze die existierende `@NativeCoroutinesState`-Konvention aus dem Projekt — Pattern aus Phase 22 / 15 / 17 wiederverwenden.)

### `AiGenerationMiniBar` View

```swift
struct AiGenerationMiniBar: View {
    let state: AiGenerationState
    let onTap: (AiType) -> Void

    private var visible: Bool {
        state is AiGenerationStateGenerating || state is AiGenerationStateSuccess
    }

    private var activeType: AiType? {
        if let g = state as? AiGenerationStateGenerating { return g.type }
        if let s = state as? AiGenerationStateSuccess { return s.type }
        return nil
    }

    var body: some View {
        Group {
            if visible {
                HStack(spacing: 8) {
                    content
                }
                .padding(.horizontal, 16)
                .frame(maxWidth: .infinity)
                .frame(height: 44)
                .background(Color(.secondarySystemBackground))
                .contentShape(Rectangle())
                .onTapGesture {
                    if let type = activeType { onTap(type) }
                }
                .transition(.asymmetric(
                    insertion: .move(edge: .bottom).combined(with: .opacity),
                    removal: .move(edge: .bottom).combined(with: .opacity)
                ))
            }
        }
        .animation(.easeInOut(duration: 0.3), value: visible)
    }

    @ViewBuilder
    private var content: some View {
        if let g = state as? AiGenerationStateGenerating {
            TypingIndicatorDots()
            Text(g.type == .workout ? "KI generiert Workout…" : "KI generiert Mahlzeit…")
                .font(.body)
                .foregroundColor(.secondary)
                .frame(maxWidth: .infinity, alignment: .leading)
                .accessibilityLabel("KI-Generierung läuft")
        } else if let s = state as? AiGenerationStateSuccess {
            Image(systemName: "checkmark.circle.fill")
                .foregroundColor(.accentColor)
                .font(.system(size: 18))
            Text(s.type == .workout
                 ? "Workout bereit — tippen zum Ansehen"
                 : "Mahlzeit bereit — tippen zum Ansehen")
                .font(.subheadline)
                .fontWeight(.semibold)
                .foregroundColor(.primary)
                .frame(maxWidth: .infinity, alignment: .leading)
                .accessibilityLabel(s.type == .workout
                                    ? "Workout bereit, tippen zum Ansehen"
                                    : "Mahlzeit bereit, tippen zum Ansehen")
        }
    }
}
```

### `TypingIndicatorDots` View

```swift
struct TypingIndicatorDots: View {
    @State private var phase: Double = 0

    var body: some View {
        HStack(spacing: 4) {
            ForEach(0..<3) { index in
                Circle()
                    .fill(Color.secondary)
                    .frame(width: 6, height: 6)
                    .opacity(alphaFor(index: index))
            }
        }
        .onAppear {
            withAnimation(.linear(duration: 1.2).repeatForever(autoreverses: false)) {
                phase = 1.0
            }
        }
    }

    private func alphaFor(index: Int) -> Double {
        // Sequenzielle Pulse 0.3 → 1.0 → 0.3, 200ms Stagger pro Dot
        let normalized = (phase * 1200 - Double(index) * 200).truncatingRemainder(dividingBy: 1200) / 1200
        let pulse = abs(sin(normalized * .pi))
        return 0.3 + 0.7 * pulse
    }
}
```

Falls die Animation-Math zu komplex ist: alternatives Muster mit drei separaten `@State`-Animationen + `DispatchQueue.main.asyncAfter` für den 200ms-Stagger — siehe 23-UI-SPEC.md "iOS Handoff Notes" für die einfachere Variante (`withAnimation(.easeInOut(duration: 0.6).repeatForever()) ...`).

## 3. Pitfalls

### Pitfall 1: State-Branch fehlt für Error
Mini-Bar darf bei `AiGenerationStateError` NICHT sichtbar sein (D-23-10). Im SwiftUI-Code: `visible`-Computed-Property prüft nur `Generating` + `Success` — Error landet in `else`.

### Pitfall 2: Tab-Switch vor Navigation
`selectedTab = X` MUSS vor jeglicher NavigationPath-Manipulation. Wenn beide gleichzeitig oder Navigation zuerst: andere Tab-Sicht macht push, sichtbarer Tab nicht.

### Pitfall 3: KMP-NativeCoroutines Sealed-Class-Casting
`AiGenerationState` ist Kotlin-sealed → in Swift sind die Subtypen flach (KMP-Native-Konvention): `AiGenerationStateIdle`, `AiGenerationStateGenerating`, `AiGenerationStateSuccess`, `AiGenerationStateError`. Pattern-Match via `if let g = state as? AiGenerationStateGenerating`.

### Pitfall 4: TabView-Inset
Der `TabView` in iOS nimmt am unteren Rand automatisch Safe-Area-Inset. Wenn die Mini-Bar über `TabView` rendert, schiebt der `VStack` den `TabView` automatisch nach oben — kein manuelles Padding nötig. Falls das visuell nicht funktioniert: `safeAreaInset(edge: .bottom)` auf den `TabView` legen statt äußerer `VStack`.
