## Spacing Scale

Declared values (multiples of 4; mapped to Compose `dp` units):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4dp | Icon gaps, inline padding between stepper value and label |
| sm | 8dp | Chip horizontal gap in `LazyRow`, between icon and text in mini-bar |
| md | 16dp | Horizontal screen padding, vertical section padding in `WorkoutFormBody` |
| lg | 24dp | Vertical spacing between sections (`verticalArrangement = spacedBy(20.dp)` rounds to 24dp token; apply 24dp for new Sets-Stepper row gap) |
| xl | 32dp | Empty/error state outer padding (`padding(32.dp)` — pre-existing) |
| 2xl | 48dp | Minimum tappable height for primary CTA Button (`heightIn(min = 48.dp)` — pre-existing) |
| 3xl | 64dp | Icon size in empty/no-key state (`size(64.dp)` — pre-existing) |

Exceptions:
- Mini-bar height: 44dp (D-23-05). Matches iOS minimum touch target and pre-existing 44dp convention from WorkoutSessionScreen end-button touch target.
- Sets-Stepper row: horizontal spacing between `IconButton` and value label = 12dp (matches the pre-existing `exerciseCount` stepper row at `spacedBy(12.dp)` — D-23-03).
- Vertical gap between form sections: 20dp (matching pre-existing `WorkoutFormBody` `verticalArrangement = Arrangement.spacedBy(20.dp)` — do not change to 24dp token; preserve existing rhythm).

## Color

Source: `Theme.kt` — dynamic accent via `PumpernickelTheme(accentColorKey)`. Default accent: `green` (`0xFF66BB6A`). All color references below use M3 role tokens.

| Role | M3 Token (light) | Example hex (green accent) | Usage |
|------|-----------------|---------------------------|-------|
| Dominant (60%) | `colorScheme.surface` / `colorScheme.background` | `#FFFFFF` | Screen backgrounds, scaffold background |
| Secondary (30%) | `colorScheme.surfaceVariant` | `#F5F5F5` | Mini-bar container background, card backgrounds, streaming panel |
| Accent (10%) | `colorScheme.primary` | `#66BB6A` | Reserved-for list below |
| Destructive | `colorScheme.error` | `#B3261E` | Error state title text only — not used for new components in this phase |

Accent (`colorScheme.primary`) is reserved for:
1. Sets-Stepper `IconButton` icons when enabled (tint follows M3 `IconButton` default — uses `onSurface`, not `primary`; accent appears only on the Generating-state `Icon(AutoAwesome)` tint and the `Button` background via M3 defaults).
2. Mini-bar checkmark icon in `Success` state.
3. Primary CTA `Button` background ("Generieren") — inherits M3 `Button` default.

Mini-bar background color: `colorScheme.surfaceVariant` (matches streaming panel container — `0xFFF5F5F5` light / `0xFF2B2930` dark). Do NOT use `primary` or a tinted surface for the mini-bar — it must be a subtle persistent element, not a call-to-action banner.

Mini-bar text color: `colorScheme.onSurfaceVariant` for Generating label; `colorScheme.onSurface` for Success label (stronger contrast signals readiness).

## Component Inventory

### New: Sets-Stepper Row (Android — `WorkoutFormBody`)

- Pattern: direct copy of the pre-existing `exerciseCount` stepper row (lines 190–213 in `AiWorkoutGenScreen.kt`).
- Label above: `SectionLabel("Anzahl Sätze")` — same `labelLarge` + SemiBold + `onSurfaceVariant` style.
- Row layout: `Row(horizontalArrangement = spacedBy(12.dp), verticalAlignment = CenterVertically)`.
- Decrement button: `IconButton(onClick = { onSetsPerExerciseChanged(state.setsPerExercise - 1) }, enabled = state.setsPerExercise > 1)` with `Icon(Icons.Default.Remove, "Weniger Sätze")`.
- Value display: `Text("${state.setsPerExercise} Sätze", style = titleMedium, fontWeight = SemiBold, modifier = Modifier.weight(1f))`.
- Increment button: `IconButton(onClick = { onSetsPerExerciseChanged(state.setsPerExercise + 1) }, enabled = state.setsPerExercise < 6)` with `Icon(Icons.Default.Add, "Mehr Sätze")`.
- Range: 1–6. Default: 3 (D-23-01).
- Position in form: after "Anzahl Übungen" row, before "Aufteilung" dropdown.

### New: Background Mini-Bar (Android — `MainScreen`)

- Placement: inside the outer `Box(modifier = Modifier.fillMaxSize())` in `MainScreen`, rendered as a sibling to `Scaffold` but positioned at the bottom using `Alignment.BottomCenter` or a `Column` that wraps `Scaffold`'s `bottomBar` content area. Specifically: inject the mini-bar as an additional composable stacked between the `Scaffold` inner content and the `NavigationBar`. The cleanest approach: replace the current `Scaffold(bottomBar = { NavigationBar {...} })` with a `Column`-based layout where mini-bar sits between content and `NavigationBar`, OR render the mini-bar inside the `Scaffold.bottomBar` as a `Column { MiniBar(); NavigationBar() }`.
- Height: 44dp fixed (`height(44.dp)`).
- Width: `fillMaxWidth()`.
- Background: `colorScheme.surfaceVariant` (use `Surface` or `Box` with `background(colorScheme.surfaceVariant)`).
- Visibility: only rendered when `AiGenerationState` is `Generating` or `Success`. When `Idle` or `Error`: height = 0 (use `AnimatedVisibility` with `slideInVertically` from bottom / `slideOutVertically` to bottom — matches WhatsApp typing-indicator behavior).

#### Mini-bar content — Generating state

```
Row(verticalAlignment = CenterVertically, modifier = Modifier.fillMaxSize().padding(horizontal = 16.dp)) {
    TypingIndicatorDots()   // animated 3-dot composable, see below
    Spacer(width = 8.dp)
    Text(label, style = bodyMedium, color = onSurfaceVariant, modifier = Modifier.weight(1f))
}
```

Label (Generating): `"KI generiert Workout…"` when `AiType.WORKOUT`; `"KI generiert Mahlzeit…"` when `AiType.RECIPE` (D-23-06).

#### Mini-bar content — Success state

```
Row(verticalAlignment = CenterVertically, modifier = Modifier.fillMaxSize().padding(horizontal = 16.dp)) {
    Icon(Icons.Default.CheckCircle or Icons.Filled.Check, tint = primary, size = 18.dp)
    Spacer(width = 8.dp)
    Text(label, style = labelLarge, fontWeight = SemiBold, color = onSurface, modifier = Modifier.weight(1f))
}
```

Label (Success): `"Workout bereit — tippen zum Ansehen"` when `AiType.WORKOUT`; `"Mahlzeit bereit — tippen zum Ansehen"` when `AiType.RECIPE` (D-23-07).

Tap interaction (Success and Generating): `clickable { onMinIBarTapped() }` — navigates to the relevant gen-screen (D-23-08). Apply `indication = rememberRipple()` over the full row.

#### TypingIndicatorDots composable

- Three circles, diameter 6dp, color `onSurfaceVariant`.
- Horizontal spacing: 4dp between each dot.
- Animation: sequential `alpha` pulse using `InfiniteTransition` with staggered 200ms offsets per dot. Each dot animates from `alpha = 0.3f` to `alpha = 1.0f` and back, 600ms per cycle.
- Accessibility: whole mini-bar row has `contentDescription` = `"KI-Generierung läuft"` (Generating) or `"Workout bereit, tippen zum Ansehen"` (Success).

## Interaction States

### Sets-Stepper

| State | Visual |
|-------|--------|
| Default (value = 3) | Both buttons enabled, value text = "3 Sätze" |
| At minimum (value = 1) | Decrement `IconButton` disabled (`enabled = false`); M3 applies `onSurface.copy(alpha = 0.38f)` to disabled icon automatically |
| At maximum (value = 6) | Increment `IconButton` disabled |
| Mid-range | Both buttons enabled |

### Mini-Bar

| State | Visual | Tap |
|-------|--------|-----|
| Idle | Bar not rendered (0 height, AnimatedVisibility hidden) | — |
| Generating | surfaceVariant bg, 3 animated dots + label, full-width tap zone | Navigate to active gen-screen |
| Success | surfaceVariant bg, checkmark icon (primary) + bold label, full-width tap zone | Navigate to active gen-screen |
| Error | Bar not rendered (same as Idle) | — |
| Transition Idle→Generating | `slideInVertically { it }` (slide up from bottom), `fadeIn` | — |
| Transition Generating/Success→Idle | `slideOutVertically { it }` (slide down), `fadeOut` | — |

Animation duration for enter/exit: 300ms (`tween(300)`).

## iOS Handoff Notes

These constraints apply to the `23-IOS-HANDOFF.md` the user implements independently:

- Sets-Stepper: use SwiftUI `Stepper("Anzahl Sätze", value: $setsPerExercise, in: 1...6)` in `FormBody`, positioned after the `exerciseCount` stepper and before the split picker. Same German copy as Android.
- Mini-bar: render as a `VStack { miniBarView; TabView {...} }` layout in `ContentView` (or equivalent root). Height 44pt. Background `Color(.systemGray6)` (light) / `Color(.secondarySystemBackground)` (dark) to match `surfaceVariant` semantic. Tap calls the same navigation callback as the existing gen-screen entry point.
- Dots animation: use SwiftUI `withAnimation(.easeInOut(duration: 0.6).repeatForever())` staggered per dot via `DispatchQueue.main.asyncAfter`.
- iOS is user-implemented — agent scope is Android + shared KMP only (D-23-12).
