**Flags to support:**

| Flag | Default | Behavior |
|------|---------|----------|
| `--suite <workout\|recipe\|both>` | `both` | Filters `ACTIVE_SUITES`. `both` keeps both. `workout` or `recipe` selects one. |
| `--output <path>` | `runs/aggregate.json` | Replaces the hardcoded aggregate write path (3 call sites in current file). Per-run JSON files (`runs/<suite>-<modelSafe>-r<rep>.json`) are NOT affected by this flag. |
| `--models <comma-list>` | (all 5) | Filters `ACTIVE_MODELS`. Each comma-separated entry is a case-insensitive substring match against the model id. Example: `--models gpt-oss-20b,maverick` keeps `openai/gpt-oss-20b` and `meta-llama/Llama-4-Maverick-17B-128E-Instruct-FP8`. If a substring matches zero models, log a warning to stderr and continue with the remaining matches (do not die). If the resulting filtered list is empty, log a clear error to stderr and `process.exit(1)`. |
| `--reps <n>` | `3` | Replaces hardcoded `REPS`. Must be a positive integer; otherwise warn to stderr and fall back to default. |

  for (const f of args.unknownFlags) console.error(`[warn] unknown flag: ${f}`);

  const SMOKE = args.smoke;
  const OUTPUT_PATH = args.output ?? 'runs/aggregate.json';

  let ACTIVE_MODELS;
  let ACTIVE_SUITES;
  let ACTIVE_REPS;
  if (SMOKE) {
    ACTIVE_MODELS = MODELS.slice(0, 1);
    ACTIVE_SUITES = SUITES.slice(0, 1);
    ACTIVE_REPS = 1;

    ACTIVE_SUITES = args.suite === 'workout' ? SUITES.filter((s) => s.name === 'workout')
